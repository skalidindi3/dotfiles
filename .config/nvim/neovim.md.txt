Vim follows a nearly linguistic syntax: [count][operator][count][motion]

# Basic Usage

## Movement

| keys | description |
| --- | --- |
| e | "end": place cursor at the end of the current word |
| ge | "end": place cursor at the end of the previous word |
| E | "end": place cursor before the next whitespace |
| `zz` | `center screen on line` |
| `%` | `toggle between nearest pairs (braces, blocks, etc)` |

h/j/k/l  - left/down/up/right
gg or G  - top or bottom of file
( or )   - jumps to the previous/next sentence
{ or }   - jumps to the previous/next paragraph
ctrl ^   - toggle current and previous file

## Modify Text (Normal -> Insert)

| keys | description |
| --- | --- |
| a | "after": enter insert mode after current character |
| i | "insert": enter insert mode at current character |
| A | "after": enter insert mode at end of current line |
| I | "insert": enter insert mode at start of current line |
| O | create new line above current line |

## Selection

| keys | description |
| --- | --- |
| v | visual select |
| \<C-v> | block visual select |
| `V` | `visual select lines` |
| `gv` | `reselect last selection` |

## Textobjects & Motions

| keys | description |
| --- | --- |
| iw | "inner word" |
| `iW` | `"inner word" until whitespace` |
| `ap` | `"around paragraph"` |

b/B as (/{ brace shortcuts for textobjects

- ac, ic, aC text objects from plugin

## Example Combos

| keys | description |
| --- | --- |
| viwp | paste over (replacing) current word |

in visual block mode, can still do $/L to get to end, and then A for appending to those lines

# Search

## Generic Search

| keys | description |
| --- | --- |
| / | forward |
| `?` | `reverse` |
| n | next match |
| N | prev match |
| f[count][char] | "find": place cursor on next (* [count]) [char] |
| t[count][char] | "till": place cursor before next (* [count]) [char] |

## Search Selected

Search the word under the cursor or the visual selection

| keys | description |
| --- | --- |
| * | forward |
| `#` | `reverse` |
| `g*` | `forward, including partial matches` |
| `g#` | `reverse, including partial matches` |

# Registers

NOTE: best with which-key (force for this)
"[register][action]

- " unnamed register
- * system clipboard
- + system clipboard (X11)
- / last search pattern
- . last inserted test
